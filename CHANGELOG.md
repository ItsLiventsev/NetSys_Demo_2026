## [2026-11-03]

Крупная реструктуризация: материалы 2026 года разложены по разделам, в репозиторий включён архив 2022–2025.

### Добавлено

- `archive/2022`, `archive/2023`, `archive/2024`, `archive/2025` — полные слепки репозиториев `NetSys_Demo_2022`…`NetSys_Demo_2025` с сохранением истории коммитов (138 коммитов, 148 файлов, ~11 МБ). Импорт — слиянием деревьев, исходная ветка сохранена вторым родителем.
- `README.md` — навигационный хаб: быстрый старт, структура репозитория, таблицы разделов и архива, внешние ссылки.
- `docs/README.md` — карта документации и три сценария чтения (с нуля / повторение / точечно по технологии).
- `docs/00-overview.md` — общая картина: формат ДЭ ПУ, состав и вес модулей, устройства стенда 2026, ключевые параметры задания, ссылки на стенд и материалы.
- `docs/01-normative/README.md` — описание нормативных документов и требований к отчёту.
- `docs/02-modules/README.md` — оглавление чек-листов по модулям.
- `docs/03-walkthrough/README.md` — оглавление пошаговых разборов, порядок выполнения модуля 1, важные оговорки.
- `docs/04-services/README.md` — оглавление справочника на 24 разбора с описанием стенда «COD + офис A».
- `docs/images/README.md` — правила именования и требования к скриншотам.
- `archive/README.md` — описание архива, принцип «как есть», обзор каждого года, инструкции по просмотру исходной истории и по переводу старых репозиториев в архив.
- `archive/MANIFEST.md` — метаданные импорта: исходные URL, HEAD-SHA, число коммитов и файлов, объёмы, SHA коммитов-импорта, команда воспроизведения.
- `MIGRATION.md` — карта переносов «старый путь → новый путь» для всех перемещённых файлов.
- `scripts/check-links.py` — проверка относительных ссылок и путей к изображениям в markdown (по умолчанию — только документы, с `--assets` — вместе с изображениями).
- `.gitattributes` — бинарные типы для PDF/ODT/XLSX, исключение архива и документации из статистики языков.

### Изменено

- Структура каталогов: было `Разборы по модулю/` и `Разборы по заданию/` в корне, стало `docs/02-modules/`, `docs/03-walkthrough/`, `docs/04-services/`, `docs/01-normative/`.
- Корневой `README.md` (75 КБ) разделён: описание → `docs/00-overview.md`, модуль 1 → `docs/03-walkthrough/module-1.md`, модуль 2 (задания 1–4) → четыре файла в `docs/03-walkthrough/`. Содержимое перенесено без изменений.
- Имена файлов приведены к ASCII-slug: `КОД 09.02.06-1-2026 Том 1 (Общес.pdf` → `kod-09.02.06-1-2026-tom1.pdf`, `Система оценивания.pdf` → `grading-system-2026.pdf`, `Пример отчета на ДЭ.odt` → `report-sample-2026.odt`.
- Файлы `task1-samba-dc (1).md` … `task4-ntp (1).md` переименованы в `module-2-task-1-samba-dc.md` … `module-2-task-4-chrony.md` (суффикс ` (1)` убран).
- `docs/02-modules/*`: обновлены ссылки между модулями и на оглавление раздела в соответствии с новыми именами.
- `docs/04-services/*`: унифицирована навигация — в каждом из 24 документов ровно одна строка навигации вверху и одна внизу: «Документация | Оглавление раздела | ← Предыдущий | Следующий →».
