# 02. Чек-листы и конспекты по модулям

Компактные разборы модулей: что требуется, какими командами выполняется, как проверить результат. Формат рассчитан на повторение — модуль читается за 10–15 минут, а не за час.

| Документ | Модуль | Объём материала |
| :-- | :-- | :-- |
| [`module-1-network-infrastructure.md`](module-1-network-infrastructure.md) | 1. Настройка сетевой инфраструктуры | 11 заданий: hostname, VLSM-адресация, пользователи, VLAN, SSH, GRE-туннель, OSPF, NAT, DHCP, DNS, часовой пояс |
| [`module-2-system-administration.md`](module-2-system-administration.md) | 2. Организация сетевого администрирования | 11 заданий: Samba AD DC, RAID, NFS + autofs, chrony, Ansible, Docker, Apache + MariaDB, проброс портов, nginx reverse proxy, HTTP-auth, Яндекс Браузер |
| [`module-3-network-operations.md`](module-3-network-operations.md) | 3. Эксплуатация сетевой инфраструктуры | 8 заданий: VPN (WireGuard/IPsec), межсетевой экран, Zabbix, rsyslog + logrotate, CUPS, Ansible-инвентаризация, fail2ban, резервное копирование |

## Как пользоваться

1. Открыть модуль и пройти по чек-листу сверху: он показывает, какие пункты задания закрыты, а какие нет.
2. По каждому пункту в документе есть раздел «Задание N»: команды для стенда, ожидаемый результат и проверка.
3. Если нужна детализация по технологии — перейти в [`../04-services`](../04-services/README.md) (BIND, FRR, Samba AD, chrony, Zabbix, NFS, iSCSI, LVM и др.).
4. Если нужен полный пошаговый разбор выполнения — [`../03-walkthrough`](../03-walkthrough/README.md). Там же разобраны типичные ошибки и «что делать, если не работает».

## Важные оговорки

- В чек-листах модулей 2 и 3 перечислены **все** задания, включая те, что пока не разобраны подробно (Ansible, Docker, CUPS, fail2ban, Кибер Бэкап). Для них указаны команды и порядок действий, но без пошаговых скриншотов.
- Адресные планы в конспектах отличаются от плана в пошаговом разборе модуля 1: конспекты писались как обобщённая схема (VLSM 10.10.x/172.16.x), разбор — под конкретную сборку стенда. На экзамене считайте адресацию сами по требованиям задания и заносите её в отчёт.
- Баллы и время (25–27 / 24 / 24 балла) взяты из конспектов. Сверяйтесь с [`../01-normative/grading-system-2026.pdf`](../01-normative/grading-system-2026.pdf).
