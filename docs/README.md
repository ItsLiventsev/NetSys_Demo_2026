## Три способа читать эти материалы

1. **С нуля.** `00-overview.md` → `01-normative/` → `03-walkthrough/module-1.md` → `03-walkthrough/module-2-task-1-samba-dc.md` → остальные задания модуля 2.
2. **Повторение перед экзаменом.** `02-modules/module-1-network-infrastructure.md` → `02-modules/module-2-system-administration.md` → `02-modules/module-3-network-operations.md`, по каждому пункту чек-листа — команда в `04-services/`.
3. **Точечно по технологии.** Сразу в `04-services/`: нужный файл + перекрёстные ссылки на модуль, где эта технология встречается.

## Соглашения

- Разделы **02-modules** — сжатые конспекты: что сделать, какой командой, как проверить.
- Разделы **03-walkthrough** — пошаговые разборы: подробные пояснения, ожидаемый вывод, разбор типичных ошибок.
- Разделы **04-services** — справочник: технология, конфигурация, проверка, диагностика. Написан под сценарий «офис A + COD» (EcoRouter, Ideco NGFW, ALT Linux), поэтому имена устройств отличаются от стенда ПК № 8 — используйте как справочник по технологии, а не как готовый сценарий экзамена.
- Пометки **⚠️** означают, что пункт в текущем стенде не выполняется или находится в доработке (например, коммутация VLAN без виртуального коммутатора — задание 4 модуля 1).
- Пометки **«пока нет» / «на доработке»** оставлены как есть: они показывают состояние материала, а не требование задания.
- Все команды приведены для ОС стенда (ALT Linux, EcoRouter, Ideco NGFW, Windows при необходимости).

```bash
python3 scripts/check-links.py            # битые ссылки на документы
python3 scripts/check-links.py --assets   # плюс отсутствующие изображения
```

Скрипт проверяет только относительные ссылки; внешние URL не запрашиваются.
