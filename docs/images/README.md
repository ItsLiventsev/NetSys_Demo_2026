# images — скриншоты для разборов

Единый каталог для изображений, на которые ссылаются документы из [`../03-walkthrough`](../03-walkthrough/README.md) и [`../04-services`](../04-services/README.md).

## Текущее состояние

- Разметка готова: в текстах разборов уже проставлены ссылки `../images/<имя>.png`.
- Сами файлы пока не загружены: **393 уникальных изображения** ожидаются в этом каталоге.
- Проверить, чего не хватает:

  ```bash
  python3 scripts/check-links.py --assets
  ```

  Скрипт выводит список отсутствующих файлов и сводку по документам.

## Правила именования

| Что | Шаблон | Пример |
| :-- | :-- | :-- |
| Этапы модуля 2 | `NN-<сущность>.png`, где `NN` — сквозной номер | `01-domain-provision.png`, `27-exports.png` |
| Сервисы и устройства | `<устройство>_<что_показано>.png` или `<тема>-<что>.png` | `bgp_neighbor_up.png`, `zabbix-dashboard.png`, `lvm-vgcreate.png` |

Имена уже зафиксированы в текстах — новые файлы нужно класть ровно с теми именами, которые указаны в ссылках (регистр учитывается).

## Требования к скриншотам

- Кадрирование: только область с командой и её выводом, без рабочего стола и лишних окон.
- Читаемость: шрифт терминала не мельче 12–13 px; при снятии с виртуальной машины — разрешение не ниже 1280×720.
- Приватность: не должно быть реальных имён, чужих доменов и настоящих паролей (в материалах стенда используются учебные `P@ssw0rd`).
- Формат: PNG (для скриншотов терминала) или JPG (для фотографий экрана); размер файла — до 1 МБ.

## Как добавить

```bash
cp ~/screens/bgp_neighbor_up.png docs/images/bgp_neighbor_up.png
git add docs/images/bgp_neighbor_up.png
git commit -m "images: BGP-соседство (03-bgp-config)"
```

Если добавляете новый шаг в разбор — сначала вставьте ссылку `![подпись](../images/<имя>.png)` в документ, затем положите файл; так проще не потерять соответствие «текст ↔ изображение».
