Документы, по которым проводится и оценивается экзамен. Всё остальное в репозитории — это разборы и конспекты, они не заменяют эти файлы.

| Файл | Что это | Как использовать |
| :-- | :-- | :-- |
| [`kod-09.02.06-1-2026-tom1.pdf`](kod-09.02.06-1-2026-tom1.pdf) | Комплект оценочной документации 09.02.06-1-2026, том 1: описание стенда, ресурсы ВМ, задания по модулям, приложения (формы таблиц, схемы) | Источник формулировок заданий и параметров («не более 32 адресов», «порт 2026», «DNS-суффикс au-team.irpo» и т. д.) |

| [`report-sample-2026.odt`](report-sample-2026.odt) | Пример оформления отчёта участника | Взять структуру отчёта: титул, таблицы, скриншоты, подписи |

## Требования к отчёту (кратко)

- На каждый пункт, требующий отчёта, — отдельный текстовый документ; имя содержит индекс пункта и краткое описание.
- Внутри — текстовая информация, таблицы и скриншоты; скриншоты кадрируются так, чтобы относящаяся к заданию информация была читаемой.
- Итоговый файл по модулю сохраняется на рабочем месте с именем `ФамилияУчастникаМодульN` (без учёта расширения).
- Сведения об адресах заносятся в таблицу по образцу приложения (`Прил_3_О1_КОД 09.02.06-1-2026-М1`); сведения о туннеле, протоколе маршрутизации, DHCP и коммутации — в соответствующие разделы отчёта.
